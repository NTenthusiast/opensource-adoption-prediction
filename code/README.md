## 三、核心结果（真实数据）

### ① 真实数据验证（`03_regression_validation.py`）
```
Usage(t) = -0.0021 + 0.8033·Usage(t-1) + 0.2415·Desire(t-1),   R² = 0.9562
```
- **β1(采纳惯性) = 0.8033**，β1(模拟) = 0.80 → 偏差 +0.42%
- **β2(渴望转化率) = 0.2415**，β2(模拟) = 0.23 → 偏差 +4.99%
- 结论：**原论文模拟参数几乎被真实数据完美复现**；年份固定效应下仍稳健（0.8024 / 0.2430）。
- 分领域异质性：数据库 β1=0.90（惯性最强）↔ 平台工具 β1=0.69、β2=0.37（最受意愿驱动）。

### ② SHAP 归因（`04_shap_analysis.py`）
- 测试集 R²=0.9645；「历史惯性 t-1」SHAP=0.1345 占绝对主导，
  「渴望率/缺口」类合计约 **4.79%**，证实原论文的「时间窗口稀释效应」。

### ③ 图特征（`05_graph_features.py`）
- 技术共现网络（138 节点、7364 边）+ PageRank/度/Louvain 社区特征，
  测试集 R² 由 0.9656 → **0.9719（+0.0063）**，RMSE 0.0298 → 0.0270。

### ④ 三模型对比（`06_boosting_models.py`）
| 模型 | R² | RMSE | MAE |
|---|---|---|---|
| 随机森林 RF | **0.9644** | **0.0304** | 0.0205 |
| XGBoost | 0.9610 | 0.0318 | 0.0196 |
| LightGBM | 0.9535 | 0.0347 | 0.0213 |
- 小样本（253 条）下随机森林仍是精度与稳定性最优。

### ⑤ 三维预警系统（`07_early_warning_system.py`）
- 159 项技术：衰退预警 52 项 / 增长信号 34 项 / 观察稳定 73 项。
- 衰退预警示例：JavaScript(−0.21)、MySQL(−0.20)、HTML/CSS(−0.19)、jQuery(−0.18)。
- 增长信号示例：Rust(+0.148)、Kubernetes(+0.145)、Go(+0.107)、Docker(+0.086)。

## 五、已知局限与可扩展方向

1. **跨年技术名对齐**：不同年份存在 `Bash/Shell`、`Bash/Shell/PowerShell` 等变体，
   当前仅做基础归一化，仍有少量技术被拆成多行；可进一步完善别名表。
2. **年份窗口**：早期建模用 2018–2022；近期双源预警另建 2018–2025 扩展面板，并用 2022–2024 年预警检查截至 2025 年的结果。调查技术选项、有效回答数会跨年变化。
3. **因果性**：回归揭示的是统计关联，「渴望→采纳」的因果方向仍需工具变量或
   准实验设计进一步确认。
4. **图特征**：当前为静态节点特征；可将时序图神经网络（如 TGAT）作为后续方向。
